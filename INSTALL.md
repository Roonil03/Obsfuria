# Installation Instructions

1. Ensure you have `g++` (supporting C++17), `nasm`, and `make` installed.
2. Run `make` to build the `Obsfuria` binary. Input the password when prompted. You can check the makefile over [here](./Makefile)
3. Run `make install` to copy the binary to your `/usr/local/bin` folder.
4. Execute the game globally by typing `obsfuria`.
